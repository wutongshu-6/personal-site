# 个人作品集网站

基于 React + Vite 的自然系个人作品集首版，适合 PC 端浏览，版心最大宽度约 1700px。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173/` 即可预览。

## 生产构建

```bash
npm run build
npm run preview
```

## 内容在哪里改

所有文案、项目、优势、时间线和联系方式都集中在 `src/data.js`，后续提供截图或参考站时可以直接在这里调整。

> 当前邮箱与 GitHub 是占位信息，请替换为你的真实联系方式。
